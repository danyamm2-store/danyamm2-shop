Наличие, цены FunPay и Telegram для всех лотов. Нажми «Сохранить», сайт обновится примерно за минуту.

Как получить токен:
1. Открой github.com → фото профиля → Settings → внизу Developer settings.
2. Personal access tokens → Fine-grained tokens → Generate new token.
3. Название любое. Срок (Expiration) выбери самый длинный.
4. Repository access → Only select repositories → выбери danyamm2-shop.
5. Permissions → Repository permissions → Contents → Read and write.
6. Нажми Generate token, скопируй и вставь сюда. Никому его не показывай.
